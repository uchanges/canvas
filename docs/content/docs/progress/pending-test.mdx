# 待测试事项

- 平台入口：访问根路径、旧的图片/视频/配置路径和未知路径时都应进入 `/canvas`；导航中只显示「我的画布」，不显示本地 Agent 或本地 API Key 配置入口。
- 登录和项目：未登录时跳转 DEEIX 登录页；登录后可创建、重命名、删除、刷新和跨设备打开同一画布，项目、节点、连线与媒体均来自服务端。
- 模型目录：图片、文本、视频、音频节点以及配置节点四种模式都只显示 DEEIX 返回的当前用户可用模型；选择的模型与实际请求模型一致。
- 任务流：图片、文本、视频、音频生成均请求 DEEIX API。视频、音频生成成功后刷新项目应正常显示文件；在流式生成中刷新则显示“生成已中断，请重新生成”，不得请求图片 Job 恢复接口。
- 保存：编辑节点、拖拽或改变视口后顶部应立即显示保存中；在防抖尚未触发时关闭标签页应有离开提示，保存完成后提示消失。
- 部署：容器运行时设置 `DEEIX_API_BASE_URL`、`DEEIX_LOGIN_URL` 后应写入 `config.js`；使用 `VITE_BASE=/canvas/` 构建时，路由与静态资源应在反向代理子路径下正常工作。
