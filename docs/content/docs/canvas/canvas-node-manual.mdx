# 画布节点操作手册

## 文本与图片

- 文本节点可记录提示词或生成文本；空文本节点生成后直接回填，已有文本修改时会在右侧创建结果节点。
- 图片节点可生成图片或基于已有内容继续编辑。多图结果以主图和子图的形式保存，均关联 DEEIX 文件 ID。
- 节点下方输入框支持 `@` 引用已连接资源，提交时由服务端校验文件与项目归属。

## 配置节点

- 配置节点可以切换图片、文本、视频、音频模式，读取上游连线的文本与媒体作为输入。
- 每种模式的模型选择器都从 DEEIX 获取当前账号可用模型；选择结果只作用于该节点。
- 图片生成支持服务端 Job 恢复。文本、视频和音频为流式请求，页面刷新后需重新生成。

## 视频与音频

- 视频节点目前支持提示词和至多一张参考图片；音频节点目前只接受文本输入。
- 生成成功的媒体写入服务端文件库，刷新项目后会重新读取展示地址。

## 推荐流程

1. 新建文本节点，整理创作意图。
2. 连接图片或配置节点，选择 DEEIX 模型与参数。
3. 生成结果后继续连线、编辑或创建视频、音频节点。
4. 等待顶部状态显示已保存后离开；保存冲突时重新打开项目处理。
