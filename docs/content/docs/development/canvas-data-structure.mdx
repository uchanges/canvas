# 画布数据结构

平台版使用 DEEIX 的 `canvas_projects` 和场景接口保存画布。Zustand 只保存当前会话缓存，不能作为项目持久化或跨设备同步来源。

## 场景

```ts
type RemoteCanvasScene = {
  nodes: CanvasNodeData[];
  connections: CanvasConnection[];
  chatSessions: CanvasAssistantSession[];
  activeChatId: string | null;
  backgroundMode: "lines" | "dots" | "blank";
  showImageInfo: boolean;
  viewport: { x: number; y: number; k: number };
};
```

保存时前端提交完整场景与 `sceneRevision`。服务端以 revision 检测并返回冲突，前端不得覆盖冲突场景。

## 节点与媒体

```ts
type CanvasNodeData = {
  id: string;
  type: "image" | "text" | "config" | "video" | "audio" | "group" | string;
  title: string;
  position: { x: number; y: number };
  width: number;
  height: number;
  metadata?: CanvasNodeMetadata;
};
```

媒体节点持久化 `fileId`、`mimeType`、字节数、尺寸和时长。`content` 是由已鉴权文件响应派生的内存展示地址，不能使用或保存 `blob:` URL、Base64 大文件或本地 `storageKey`。

生成状态中的图片 Job ID 可用于刷新恢复；文本、视频、音频流的临时 `runId` 不能写入场景恢复字段。

## 连线

```ts
type CanvasConnection = {
  id: string;
  fromNodeId: string;
  toNodeId: string;
};
```

服务端至少校验节点 ID 唯一、连线端点存在、场景 JSON 可解析和体积上限；插件节点元信息由前端和插件解释。
