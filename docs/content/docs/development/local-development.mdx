# 本地开发

## 前端

```bash
cd web
npm install
npm run dev
```

前端默认请求 `/api/v1`。本地 DEEIX 不同源时，设置 `VITE_DEEIX_API_BASE_URL`、`VITE_DEEIX_LOGIN_URL`，并在 DEEIX 配置允许对应 Origin 与 Cookie。

## 开发约定

- 浏览器只请求 `web/src/services/api/` 中的 DEEIX 封装；组件不直接拼接服务 URL 或读取令牌。
- 项目、模型、文件和任务以 DEEIX 返回数据为准，不新增 IndexedDB 作为平台业务持久化。
- 上游模型密钥、渠道协议和自定义请求脚本仅属于 DEEIX 管理后台，不进入前端。
- 文本、视频、音频生成均为 SSE 请求；组件卸载时必须传递 AbortSignal。
