# 快速开始

## 本地启动

```bash
git clone https://github.com/uchanges/canvas.git
cd canvas/web
npm install
npm run dev
```

访问 `http://localhost:3000`。开发服务器默认请求同源 `/api/v1`，请将其反向代理到 DEEIX 服务，或设置：

```bash
VITE_DEEIX_API_BASE_URL=http://localhost:8080/api/v1
VITE_DEEIX_LOGIN_URL=http://localhost:8080/login
```

## 首次使用

1. 在 DEEIX 登录页完成登录。
2. 返回画布后创建项目。
3. 从 DEEIX 模型目录选择当前账号可用的模型，再开始生成。

平台版不要求也不提供浏览器中的上游 Base URL、API Key 或 WebDAV 配置。
