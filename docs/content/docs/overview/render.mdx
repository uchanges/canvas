# Render 部署

将仓库作为静态站点构建，根目录设为 `web`，构建命令为 `npm install && npm run build`，发布目录为 `dist`。

设置构建期变量 `VITE_DEEIX_API_BASE_URL` 和 `VITE_DEEIX_LOGIN_URL`，或使用同源反向代理时保留默认 `/api/v1` 与 `/login`。生产环境应由 DEEIX 或网关正确配置 CORS、Cookie 与 HTTPS。

Render 只托管画布静态文件，不替代 DEEIX Go API、Worker、数据库或文件存储。
