# 功能介绍

无限画布是 DEEIX 的画布创作前端。浏览器负责画布交互和节点展示，DEEIX 服务端负责账号、权限、模型、项目、文件、生成任务和计费。

## 账号与项目

- 通过 DEEIX 登录页完成认证，Access Token 仅保存在内存，刷新凭据使用 HttpOnly Cookie。
- 画布项目创建、读取、重命名、删除和场景保存均以服务端数据为准。
- 保存使用版本号避免静默覆盖；存在未保存修改时离开页面会提示。

## 节点与生成

- 文本、图片、视频、音频和配置节点可通过连线组合创作流程。
- 模型下拉由 DEEIX 返回当前用户可用的目录，配置节点与节点快捷生成使用同一模型来源。
- 图片任务使用可恢复的 Job 和 SSE；文本、视频、音频使用项目级流式接口，结果与文件 ID 写回云端场景。
- 视频与音频流是请求生命周期内的任务：刷新页面后会明确标记为中断，用户可重新生成，不会误按图片 Job 恢复。

## 文件与插件

- 上传的图片、视频和音频由 DEEIX 文件服务保存，画布只持久化文件 ID 和必要元信息。
- 支持远程节点插件；插件 AI 能力同样通过 DEEIX 项目接口调用。

## 平台边界

- 前端不提供上游 Base URL、API Key、协议选择或浏览器自定义请求脚本入口。
- 本地 Agent 相关源码为开发保留内容，平台导航、自动连接和用户入口均已隐藏。
- 浏览器本地存储仅用于主题等小型偏好和短生命周期缓存，不是平台画布的持久化或同步来源。
