# Docker 部署

镜像只提供 Vite 构建后的静态画布前端，DEEIX API、数据库、Worker 和文件存储须单独部署。

## 构建与运行

```bash
docker build -t canvas --build-arg VITE_BASE=/ .
docker run -d -p 3000:3000 \
  -e DEEIX_API_BASE_URL=/api/v1 \
  -e DEEIX_LOGIN_URL=/login \
  canvas
```

容器启动时会生成 `config.js`，因此可在不重新构建镜像的情况下设置 `DEEIX_API_BASE_URL`、`DEEIX_LOGIN_URL` 和统计配置。

## 子路径部署

若画布部署在 `/canvas/`，构建时设置：

```bash
docker build -t canvas --build-arg VITE_BASE=/canvas/ .
```

反向代理应将 `/canvas/` 映射到该静态应用，并将 `/api/` 转发到 DEEIX API。Vite `base`、React Router `basename` 和反向代理路径必须一致。生产环境的静态资源路径组合需要在目标网关中人工验证。

## 数据与安全

画布项目、媒体文件、模型权限和生成任务均由 DEEIX 保存。浏览器不保存平台上游 API Key；Access Token 仅在内存中，刷新凭据使用 Cookie。
